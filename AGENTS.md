# CPM demo pública

- Esta carpeta es un repositorio independiente del simulador privado.
- Mantener todos los datos sintéticos y originales. Nunca copiar bases, nombres,
  capturas, resultados, secretos ni historia del simulador privado.
- Mantener el runtime estático sin dependencias externas ni peticiones de datos.
- Explicar siempre las simplificaciones. El PPP es un puntaje ponderado, no una
  probabilidad de ganar ni una evaluación oficial de la Contraloría.
- No confundir combinaciones teóricas con equipos viables, ni máximos de un
  escenario con el óptimo global de una cartera.
- Cualquier cambio de algoritmo debe pasar `npm test` y `npm run check`.
- El portfolio replica solo index.html, styles.css, app.js, data.js, engine.js,
  worker.js y favicon.svg. Mantener copias idénticas cuando se actualicen juntas.
- Respetar las reglas globales de rama, commit, privacidad y diálogos de UI.
